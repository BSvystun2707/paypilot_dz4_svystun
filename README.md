Прогноз до прогону lesson-05

Очікується, що профіль lesson-05 може спричинити втрату або спотворення значень, які потрібно зберігати між ходами діалогу. Основні ризики — втрата числової суми чи дати транзакції (D06) та спотворення reason code або строку подання спору (D07).

CONV-H01: можливе порушення інваріантів суми та reason code на ході 5 після сторонніх запитань; filing window може бути втрачений або змінений на ході 7.

CONV-H02: можливе порушення суми чи reason code на ході 5 після перемикання тем; дата транзакції та пов’язаний із нею дедлайн можуть бути відтворені неправильно на ході 7.

CONV-H03: можливе спотворення reason code або filing window на ході 5; на ході 7 може проявитися неправильний дедлайн або суперечність щодо відкритого строку.

CONV-H04: контрольний сценарій без сторонніх тем має бути стійкішим. Проте очікується ризик суперечності reason code або filing window на ходах 5 і 7, якщо деградація зачіпає саме збереження інваріантів, а не лише перемикання тем.

CONV-H05: найвищий ризик через довжину діалогу та повторні уточнення. Можлива втрата суми, дати чи reason code на ходах 5 і 8; filing window або дедлайн можуть бути відтворені неправильно на ході 10.
