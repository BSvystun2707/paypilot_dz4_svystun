Набір містить 5 діалогових кейсів для перевірки збереження інваріантів між ходами розмови. Перевіряються сума транзакції, reason code, дата транзакції, filing window та дедлайн подання спору.

## Діалогові кейси

| **ID** | **Роль у плані** | **Довжина · сутності · перемикання** | **Інваріанти** |
|---|---|---|---|
| `CONV-H01` | контроль | 7 ходів · 2 сутності · 2 перемикання тем | сума спору, reason code, filing window |
| `CONV-H02` | ізоляція осі | 7 ходів · 3 сутності · 3 перемикання тем | сума спору, reason code, дата транзакції |
| `CONV-H03` | ізоляція осі | 7 ходів · 2 сутності · 2 перемикання тем | reason code, filing window, filing deadline |
| `CONV-H04` | контроль | 7 ходів · 2 сутності · 0 перемикань тем | reason code, filing window, filing deadline |
| `CONV-H05` | найгірший | 10 ходів · 3 сутності · 3 перемикання тем | сума спору, дата транзакції, reason code, filing window |

## Прогони

| **Прогін** | **Профіль** | **Результат** | **Звіт** |
|---|---|---|---|
| Baseline | `clean` | 5/5 сценаріїв пройшли | `evals/reports/l05_dialogs-clean-20261029T222121.json` |

У профілі lesson-05 не пройшли CONV-H03 та CONV-H05. У CONV-H03 на одному з прогонів reason code змінився з goods_not_received на service_not_rendered на ході 5. У CONV-H05 перевірка дати транзакції на ходах 5 і 8 не пройшла: відповідь містила дату у форматі 20 July 2026 замість очікуваного ISO-формату 2026-07-20.

Прогноз до прогону lesson-05

Очікується, що профіль lesson-05 може спричинити втрату або спотворення значень, які потрібно зберігати між ходами діалогу. Основні ризики — втрата числової суми чи дати транзакції (D06) та спотворення reason code або строку подання спору (D07).

CONV-H01: можливе порушення інваріантів суми та reason code на ході 5 після сторонніх запитань; filing window може бути втрачений або змінений на ході 7.

CONV-H02: можливе порушення суми чи reason code на ході 5 після перемикання тем; дата транзакції та пов’язаний із нею дедлайн можуть бути відтворені неправильно на ході 7.

CONV-H03: можливе спотворення reason code або filing window на ході 5; на ході 7 може проявитися неправильний дедлайн або суперечність щодо відкритого строку.

CONV-H04: контрольний сценарій без сторонніх тем має бути стійкішим. Проте очікується ризик суперечності reason code або filing window на ходах 5 і 7, якщо деградація зачіпає саме збереження інваріантів, а не лише перемикання тем.

CONV-H05: найвищий ризик через довжину діалогу та повторні уточнення. Можлива втрата суми, дати чи reason code на ходах 5 і 8; filing window або дедлайн можуть бути відтворені неправильно на ході 10.
